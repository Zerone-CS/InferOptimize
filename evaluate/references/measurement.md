# 测量契约与可信基线

需要：任务目标与质量/SLO、服务/配置/源码身份、负载与客户端策略、已有契约/run，或允许采集的范围和预算。
本能力返回基线候选证据，不自行设定或晋级全局基线。

## 执行

先读 [计量定义](measurement_contract.md)。调用工具查 [工具用法](tool_usage.md)；公开机器字段以 [数据接口](tool_contract.md) 为准，研究记录见 [评估记录](records.md)。

1. 区分固定请求集吞吐、固定到达负载体验与受约束容量；固定成功/输出规则、系统边界、完整窗口及保护指标。已有目标或阈值需要修改时，返回变更请求，不自行放宽标准。
2. 建立 `X_out=N_Y/T`：仅计最终成功请求的实测有效输出，完整时间保留失败、等待与收尾。核对 EOS、停止、reasoning/特殊 token 与用量语义；缺计数保持 unknown，不能用 max_tokens、chunk、padding、输入、重算或 rank 副本补账。
3. 核对目标实例、配置实际生效、源码及客户端身份，判断已有数据是否可复用。质量未评估、配置未核验时保留真实状态。
4. 在委托范围内分析或采集；预热置于窗口外，诊断与正式计分分别标明目的。保留 `manifest.json`、`requests.jsonl`、`workload.json`、`metadata.json` 四件原件及实际退出码；窗口内编译、失败与等待不得删去。
5. 重算输出、墙钟时间、请求分位数与在途积分，解释不一致后才称可信总账。计量有效不等于环境无干扰、质量通过或收益可重复。
6. 按波动与待辨别收益安排重复。容量任务另验发送滞后、持续供给和队列稳定性；有限批次曲线不证明可持续容量。输出长度与质量同时检查，同 prompt/max_tokens 不保证实际产出相同。

| 工具 | 用途 |
|---|---|
| [prepare_metadata.py](../scripts/prepare_metadata.py) | 保存契约、环境、配置及核验来源 |
| [benchmark.py](../scripts/benchmark.py) | 采集有限请求集的用量、时间和终态 |
| [validate_run.py](../scripts/validate_run.py) | 校验原件并重算总账 |

工具不提供逐 token ITL、引擎实际 batch 或完整投机轮。缺这些证据时返回采集需求，供主入口委托 [diagnose](../../diagnose/SKILL.md)；内部因子不全不妨碍交付可信 `N_Y/T`。

## 完成与产物

交付契约/来源引用、原始 run、校验与重复报告、输出分布、质量/SLO 状态、供给边界和补证建议；不更新 campaign state。
审计可在问题完整说明后 `completed`；委托要求可信基线时，必须有可重算的有效 run。缺少影响结论的计数、终态、窗口或身份时返回 `needs_evidence` 及最小补证动作；采集/对账失败保留部分产物和恢复边界。
